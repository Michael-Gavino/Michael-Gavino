## 👋 Sobre mí

Hola, soy **Michael Gavino Isidro**, estudiante de **Ingeniería Informática** en la **Universidad Peruana Cayetano Heredia (UPCH)**.  
Me apasiona construir soluciones reales combinando **software, hardware e inteligencia artificial**.

Desarrollo proyectos orientados a:

- 🧠 **Machine Learning y Deep Learning**
- 📊 **Análisis de datos y visualización**
- 🔒 **Ciberseguridad y auditoría informática**
- 🔌 **IoT y sistemas embebidos (Arduino/ESP32)**
- 🧪 **Prototipos electrónicos para medición de parámetros de calidad del agua**
- 🕹️ **Videojuegos en Python (Pygame) con interacción multiusuario y base de datos**
- 🖥️ **Automatización y desarrollo backend**

Mi enfoque principal es crear sistemas **eficientes, escalables y con impacto real**.
